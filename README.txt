FWD.TECH WEBSITE
================

Files:
- index.html: Homepage
- about.html: About page
- services.html: Services page
- projects.html: Projects/capabilities page
- testimonials.html: Testimonial placeholders
- contact.html: Contact page with WhatsApp enquiry form and QR code
- styles.css: Shared responsive styling and animations
- script.js: Mobile navigation, active link, reveal animations, contact form
- assets/: supplied FWD.TECH logo, code illustrations, WhatsApp QR

HOW TO RUN
1. Extract this ZIP.
2. Open index.html in a browser, or upload the folder to your hosting provider.
3. Keep all files and folders in the same structure.

IMPORTANT BEFORE PUBLISHING
- The project cards are illustrative concepts. Replace them with real completed projects before describing them as client work.
- The testimonial section contains clearly marked placeholders. Replace them with genuine reviews and get permission from the reviewers.
- The enquiry form opens WhatsApp with a pre-filled message; the visitor taps Send in WhatsApp. The website does not store form submissions.
- Google Fonts load from the internet; fallback fonts are included.
